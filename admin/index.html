  1. Auf GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access: nur disorder119/disorder119-shop
  3. Permissions: Contents → Read and write
  4. Token unten einfügen und eine Passphrase vergeben, die es verschlüsselt.

Der Token wird mit dieser Passphrase verschlüsselt (AES-256-GCM, PBKDF2) im Browser gespeichert — im Klartext verlässt er ihn nie. Vergisst du die Passphrase, hilft nur ein neuer Token samt neuer Einrichtung; es gibt keine Wiederherstellung.
